# ARCH-COMP benchmark skeleton

Minimal starting point for an ARCH-COMP benchmark set: one `instances.csv` listing every
benchmark and instance for a category (`benchmark,instance`, plus optional columns such
as `timeout`), and a `data/` placeholder for the referenced model and specification files.

See the benchmark info page for how a category's benchmarks are loaded and the full
`instances.csv` format: <https://arch.repeatability.cps.cit.tum.de/benchmark/info>
